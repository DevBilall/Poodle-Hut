1. Introduction
--------------------------------------------------------------------------------
The Multimedia Information Processing (MIP) Assignment #1 focuses on building a
content-based retrieval pipeline for classifying YouTube-style videos into
predefined categories. Each video description comprises the original title and
user-assigned tags. The training corpus (4,610 videos) is used exclusively to
learn Category Discriminating Terms (CDTs), while the testing corpus (4,657
videos) is evaluated by computing cosine similarity between each test vector and
category profile vectors. Performance is reported via Mean Average Precision
(MAP), aligning with information retrieval best practices.

--------------------------------------------------------------------------------
2. Dataset Overview
--------------------------------------------------------------------------------
Training File: “Training data (Core) 4610.xlsx”
Testing File: “Testing data (Core) 4657.xlsx”
Meta Columns Used:
  • core-video-video-title
  • core-video-video-tag
  • category (training only)

Both datasets contain multilingual and noisy terms, necessitating consistent
preprocessing. An auxiliary stop-word list (“english.stop”) is provided to
standardize token filtering across experiments.

--------------------------------------------------------------------------------
3. Experimental Objectives
--------------------------------------------------------------------------------
1. Preprocess textual attributes (title + tags) for training and testing sets.
2. Generate Category Discriminating Terms with a fixed frequency threshold of 60.
3. Build category profile vectors restricted to the learned CDTs.
4. Compute cosine similarity between test vectors and category profiles.
5. Rank categories per test sample and compute Average Precision and MAP.
6. Visualize Average Precision distributions and CDT coverage across categories.

1. Library Imports

2. Data Loading
   train = pd.read_excel("Training data (Core) 4610.xlsx")
   test = pd.read_excel("Testing data (Core) 4657.xlsx")

3. Stop-word Acquisition
   with open("english.stop", "r", encoding="utf-8") as f:
       custom_stopwords = set(f.read().splitlines())

4. Preprocessing Routine
   def preprocess(text):
       if pd.isna(text):
           return ""
       text = text.lower()
       text = re.sub(r"[^a-z0-9\s]", " ", text)
       tokens = [t for t in text.split()
                 if t not in custom_stopwords and len(t) > 2]
       return " ".join(tokens)

   train["combined"] = (
       train["core-video-video-title"].fillna("") + " " +
       train["core-video-video-tag"].fillna("")
   ).apply(preprocess)

   test["combined"] = (
       test["core-video-video-title"].fillna("") + " " +
       test["core-video-video-tag"].fillna("")
   ).apply(preprocess)

5. CDT Extraction Per Category
   category_terms = {}
   for cat in sorted(train["category"].unique()):
       subset = train[train["category"] == cat]["combined"]
       vectorizer = CountVectorizer()
       matrix = vectorizer.fit_transform(subset)
       term_freq = np.asarray(matrix.sum(axis=0)).ravel()
       terms = vectorizer.get_feature_names_out()
       selected = [terms[i] for i, freq in enumerate(term_freq) if freq >= 60]
       category_terms[cat] = selected

   unique_cdts = sorted({term for terms in category_terms.values() for term in terms})
   len(unique_cdts) == 20  # documented outcome

6. Category Profile Construction
   profile_vectorizer = CountVectorizer(vocabulary=unique_cdts)
   profile_vectors = []
   category_labels = []
   for cat in sorted(category_terms.keys()):
       subset = train[train["category"] == cat]["combined"]
       matrix = profile_vectorizer.transform(subset)
       profile_vectors.append(matrix.sum(axis=0))
       category_labels.append(cat)
   profiles = np.vstack(profile_vectors).astype(float)
   profiles = normalize(profiles, norm="l2", axis=1)

7. Test Vector Encoding
   test_matrix = profile_vectorizer.transform(test["combined"]).astype(float)
   test_matrix = normalize(test_matrix, norm="l2", axis=1)

8. Cosine Similarity
   similarity_matrix = cosine_similarity(test_matrix, profiles)

7. Cosine Similarity Computation
--------------------------------------------------------------------------------
Explain the mathematical foundation:

cosine_similarity(A, B) = (A · B) / (||A|| × ||B||)

Where A and B are L2-normalized TF vectors restricted to the CDT vocabulary.
Highlight that cosine similarity is robust to vector magnitude differences and
is well-suited for sparse textual data.

10. Observations and Discussion
--------------------------------------------------------------------------------
• Specific categories with domain-focused vocabulary (How-to & Style, Pets &
  Animals, Gaming) dominate the MAP metric because their CDTs recur frequently
  in both training and testing corpora.
• Broad or generic categories (People & Blogs, Travel & Events) have sparse or
  zero high-frequency terms at the threshold of 60, leading to poor AP.
• Only 20 unique CDTs were retained, indicating a highly selective feature
  space. Lowering the threshold or adopting TF-IDF weighting could improve
  coverage but was intentionally avoided to stay aligned with the requirement.
• Cosine similarity with normalized vectors ensures fairness even when test
  videos contain fewer CDT hits.
